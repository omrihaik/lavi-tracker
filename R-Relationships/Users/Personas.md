# Personas

The users of LavieTracker. Names are omitted — this repo is public.

---

## Persona — The Logger (both parents)

Both parents share the same profile (per Parent 1, answering for both — not interviewed separately).

- **When:** Log throughout the day — not concentrated at night.
- **Main job:** Logging, far more than looking things up. Checking ("when did he last eat?") is secondary but frequent.
- **Tech comfort:** High — try every new app. Will install the PWA, explore settings, tolerate early bugs.
- **Devices:** One iPhone, one Android.
- **Biggest pain today:**
  1. Scrolling the Excel to find the right row.
  2. Typing details by hand — how the feeding went, ml amount, how the put-down went.
  3. Asking each other "when did he last eat?"
- **Implications for design:**
  - The home screen *is* the logger — no navigation before the log buttons.
  - Live status sits on the same screen, above the buttons — logging and checking in one view.
  - Details (ml, rating, crying yes/no) are taps on preset choices, never typing.
  - Time defaults to "now", editable after the fact.
  - One screen for both parents — no separate "viewer" mode.
