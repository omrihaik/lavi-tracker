# Initiative: I-01 Fast Logger

## Strategic Link
- [[S-Strategy/Strategic-Bets]]: Bet 1 — Speed drives completeness
- Why this bet now: Without fast logging there is no data. Every other initiative depends on it.

## Outcome (must be measurable)
- Metric: Taps to log, per event type
- Desired change: Every event (sleep, feeding, put-down, activity) logged in ≤ 3 taps, time defaulting to "now"
- Time horizon: Before MVP release

## Scope
- Home screen = 4 big buttons: Sleep · Feeding · Put-down · Activity
- Sleep: one button toggles "fell asleep" ↔ "woke up" based on current state
- Feeding: ml presets (e.g. 60 / 90 / 120 / 150 / other) → Good / OK / Hard
- Put-down: crying yes / no
- Activity: tummy time / trampoline / skin to skin / talking
- Edit time or delete an event after the fact
- Records who logged each event and which fields were filled (needed to measure HYP-01–03)
- Hebrew, right-to-left, dark mode, one-handed

## Out of scope
- Timers, free text, notes, any event type beyond the four (the daily checklist in I-02 is stored as events but is not a log button)
