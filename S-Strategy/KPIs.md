# KPIs

Defines how success is measured — the North Star Metric plus the supporting signals that predict it.
Agents read this for daily briefings, OKR work, and business case framing.
Update each planning cycle.

---

## North Star Metric

- **Name:** Complete sleep logs
- **Definition:** % of sleeps in a week that have all three parts logged — put-down, fell asleep, woke up. This is the minimum data needed to answer all three questions.
- **Current:** ~36% (Excel baseline — limited by put-down logging)
- **Target:** ≥ 80% within 4 weeks of daily use

## Supporting Metrics (max 3–5)

1. **Sleeps with a recorded wake-up**
   - Definition: % of sleeps with both start and end logged.
   - Current: 65% / Target: ≥ 95%

2. **Complete feeding logs**
   - Definition: % of feeding events that include both an ml amount and an experience rating.
   - Current: 44% have ml; rating not tracked / Target: ≥ 90%

3. **Taps to log**
   - Definition: Taps from opening the app to a saved event.
   - Current: N/A (Excel: find row + type) / Target: ≤ 3 for every event type

4. **Both parents logging**
   - Definition: Each parent logs at least 25% of the week's events.
   - Current: unknown / Target: true every week
