# Lavi Tracker

A baby tracking app (sleep, feeding, activity) built step by step with the AI product operating system — from strategy to shipped code.

This repo holds both the product thinking and the code, so every line of code can be traced back to a product decision.

## Structure

| Folder | What lives here |
|---|---|
| `S-Strategy/` | Vision, Product, KPIs, Strategic Bets, Constraints |
| `R-Relationships/Users/` | Personas (the parents) |
| `H-Hypotheses/` | Falsifiable hypotheses |
| `I-Initiatives/` | Initiatives linked to Strategic Bets |
| `P-Proof/` | Experiments and data reads |
| `app/` | The application code |
| `PROCESS.md` | Step-by-step log of how this was built, and why |
| `Learning.md` | Accumulated learnings |

## Privacy

Real tracking data never goes into this repo. `data/` and `*.xlsx` are git-ignored.
